# Codex Lumo Desktop

Windows 透明置顶悬浮窗。应用只读监听本机 `%USERPROFILE%\.codex\sessions` 与 `logs_2.sqlite`，将 Codex 任务生命周期映射为宠物状态。

## 使用

- 双击安装包，或直接运行便携版 `Codex-Lumo-Portable-1.0.0-x64.exe`。
- 单击悬浮窗标题区展开/收起详情，双击任意非按钮区域打开 Codex；按住任意非按钮区域都可以拖动。
- 托盘菜单可以设置窗口尺寸、贴顶自动隐藏、更新弹出时长（包括“不自动弹出”）、鼠标穿透和开机启动。
- 只有把窗口实际拖到屏幕顶边时才会进入贴顶自动隐藏；停靠显示时保留 12px 顶部留白，从顶边拖开会立即解除停靠。
- 无活动任务时会稳定保持待机状态，已结束任务的历史完成记录不会反复触发“已完成”。
- 展开详情后，额度卡片会显示本地时区下的明确重置时间；当天显示时分，跨天同时显示月日。
- 贴顶收起或从托盘隐藏时自动进入节能模式：暂停界面动画与 DOM 刷新，去重状态推送，并降低日志扫描和系统遥测频率；新回复仍可正常唤出。
- 详细任务卡会分别展示问题名称、当前动作、最近可见回复、工作区、开始时间、最后更新时间、线程短 ID 和运行时长；最多 5 个任务完整显示。
- 任务卡按“标题与状态、当前动作与耗时、最近回复、任务元信息”四层排列，避免状态栏挤占正文，更新时间使用明确的中文相对时间。
- 详情展开/收起保持当前尺寸档位的固定宽度，仅以缓动方式改变高度；重复的 `LIVE EVENTS` 区域已移除。
- 鼠标穿透后按 `Ctrl + Alt + L` 召回窗口。

紧凑态会显示 Codex 当前的高层阶段（思考、执行、等待、完成等）、CPU 和内存使用率。

Lumo 的宠物形象改编自 MIT 许可的 React Kawaii `Cyborg`：圆润的 SVG 机器人会随任务状态切换表情，待机时会随机挥手、伸展、跳舞、shuffle、moonwalk、旋转和机器人舞。

思考、执行、等待、完成、错误和离线状态也各自包含多套随机轮换动作。顶部不再显示推算百分比，而是使用不同节奏的能量条动画表达当前是否正在思考、执行、等待、完成或异常。

小尺寸使用独立的紧凑排版，不再等比缩小文字；它会隐藏次要任务名并压缩间距，同时保持任务状态、详情、CPU、内存和活动动画清晰可读。

点开详情会汇总所有仍在运行的本地 Codex 会话；监视器可从大型日志中向后定位任务起点，再以增量方式持续更新。外框使用随任务状态变速的青紫流光，没有活动任务时会停留为低亮静态边线。

系统遥测带会显示 CPU、内存和 Codex 剩余额度。额度直接读取本地 `token_count.rate_limits`，支持多个限额窗口并优先展示最接近耗尽的窗口及重置倒计时；读取不到时显示 `--`。CPU、内存与额度共用无外框的一体化布局。

所有日志和电脑状态解析都在本机完成。应用只显示高层思考阶段，不展示内部推理文本，也不会上传 Codex 日志。

## 1.2 更新

- 自动弹出只响应写入对话的 `agent_message`，包括过程回复和最终回复；`agent_reasoning` 思考摘要、工具执行、等待、中间错误和纯状态刷新都不会弹出。
- 界面改为 Windows 11 风格的深色半透明层次、Segoe UI 字体、单色强调与克制的任务流光，移除了扫描线和彩色霓虹装饰。
- 1.2.1 将额度刷新与当前任务日志解耦，汇总近期会话中的多个额度池并显示最紧张的有效额度，避免任务切换时错误跳到 100%。
- 详情窗口会随任务数增高，最多完整展示 5 个任务；只有超过 5 个时任务列表才出现滚动条。
- 主悬浮栏在“思考中 / 执行中 / 等待中”后显示当前具体动作；进度条下方显示当前问题描述，并在收到可见回复后替换为最新回复。
- 紧凑栏会在活动任务数量后显示与详情任务一致的工作区短路径。

## 1.3 OpenCode 委派关联

- 自动识别 Codex 工具调用中的 `opencode run`，并按调用 ID 归属到当前父任务。
- 只读查询 OpenCode 本地会话、消息和内容分片，显示分析中、执行工具、回复中、已完成或异常等实时阶段，以及最新内容、模型、token 和耗时。
- 使用启动时间、工作区和首条提示完成会话匹配；`-c` 连续调用合并为一个子任务并显示轮次，并行委派保持为独立子任务。
- 子任务采用 Windows 11 / Linear 式轻量嵌套层级；优先展示仍在运行与最近更新的项目，窗口只增加高度、不改变宽度。
- 刷新采用任务 ID 定向替换：未变化的父任务和子任务 DOM 保持不动，并移除全窗状态脉冲，避免阅读时整窗闪烁。
- 仅有 `task_started` 而长期没有后续事件的遗留会话会在 5 分钟后淘汰；Codex 生命周期日志已确认结束的会话也不会重复计入 Active。
